# QC aggregation vectors and H5AD export indices

Expression QC keeps vectors up to 8 MiB in memory and gives larger vectors private file-backed mappings. This applies to total counts, detected genes, mitochondrial values, retention and exclusion reasons. QC skips the mitochondrial accumulator when the feature mask is empty. CSC totals, detection and mitochondrial reductions emit at most 8,192 rows at a time. The reduction keeps the existing column-block order and count dtypes. The histogram samples included rows by block. The QC NPZ and its fields retain the previous schema.

The H5AD writer builds its retained source-row index in 8,192-row blocks into temporary storage. Signed 32-bit indices cover source row positions up to 2,147,483,647. Larger positions use 64-bit indices. Sparse lookups convert only the small query block to the index dtype and check its range before lookup. CSC exports over all features iterate a range instead of allocating an array of column positions. Cohort provenance hashes the same little-endian 64-bit source rows in blocks.

A fresh-process synthetic probe retained 3.6 million out of four million source rows. The index occupied 14.4 MB instead of 28.8 MB, and additional peak RSS during construction was 14.5 MiB instead of 27.5 MiB. Both paths produced SHA-256 `200e2951fd22338f2cba3a283a0b36afc3cdc150dd09f6db580427f8ec2dbf53` over the same canonical row integers. Tests also compare mapped CSC accumulators, mitochondrial values and reason bits against independently calculated values across the block boundary.

Mapped pages can still contribute to RSS when accessed. Scratch disk usage scales with the number of cells. Legacy annotation conversion, the CSC matrix decode itself and other cohort metadata allocations can still use memory proportional to the input. The probe isolates index construction.

Public Kang QC retained 24,562 cells and excluded 111. The Python round trip checked expression values, source rows, donor labels and source integrity. The supervised Rust test recovered the selection after worker restart and wrote the QC ZIP and retained H5AD. The portable project test saved and restored the mixed cohort, reconnected the original by SHA-256 and exported the same 12,859 retained cells again. Frontend build and 21 tests, Rust core 23 tests, the app compile check and both public integrations passed. Python ran 64 tests with two PBMC-dependent cases skipped.
