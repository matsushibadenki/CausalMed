# CausalMed roadmap

Updated: 2026-11-05 · 0.1 initial implementation

参照スレッドの研究構想を、検証可能な小さな段階へ分割しています。現在の対象は IPF 研究ワークスペースの基盤です。同梱の関係・評価値はすべて合成データであり、医学的な発見や有効性を示すものではありません。

## 0.1 — 動作するローカル基盤

- 🟢 [Done] Tauri 2 + Rust。Document / WorkspaceState / Renderer を Rust が所有し、WebView は状態の投影として動作。
- 🟢 [Done] SQLite による保存、リビジョン同期、再起動後の復元。
- 🟢 [Done] 証拠の検索・種別フィルター、出典・原文・実験条件・矛盾する記録の表示。
- 🟢 [Done] 証拠 JSON の取り込み、入力検証、重複拒否、原本バイト列の SHA-256、JSON スナップショット書き出し。
- 🟢 [Done] 反証条件を必須とする仮説作成と下書き／計画／アーカイブ管理。
- 🟢 [Done] インスペクターの右／下へのドッキング、独立ウインドウへの分離と復帰。配置ボタンのネイティブ動作を確認。
- 🟢 [Done] 選択した1関係を Rust / wgpu のネイティブウインドウで描画。大容量画像データの JS 転送なし。
- 🟢 [Done] 日本語・English・简体中文、情報ツールチップ、320 / 375 / 414 / 768px のブラウザー表示を確認。
- 🟢 [Done] 合成・単一数値の M0 対照平均評価。データセット／摂動／ドナーを分離し、ドナー単位で集計。不足時は評価を保留。
- 🟢 [Done] 独立した Python M0 参照 CLI。アプリへの sidecar 接続は未実装。
- 🟢 [Done] macOS 開発アプリのビルド、仮説保存・評価実行・再起動・パネル分離／復帰・GPU 描画・書き出し・重複取り込み拒否を実画面で確認。
